# Deploying asaanHire (free)

Frontend -> Vercel. Backend -> Render. Optional database -> Neon (free Postgres).

## 1. Backend on Render
1. render.com -> sign in with GitHub -> New -> Blueprint -> pick this repo -> Apply.
   (Or New -> Web Service: root `services/api`, build `pip install -r requirements.txt`,
   start `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, Python 3.11.)
2. Environment variables:
   - `LLM_API_KEY` = your NEW Groq key (never committed)
   - `JWT_SECRET` = auto-generated by the blueprint
   - `CORS_ORIGINS` = your Vercel URL (add after step 2), no trailing slash
3. Open `https://<your-service>.onrender.com/health` -> `{"status":"ok"}`.
   The item bank, companies and demo candidates seed themselves on boot.

## 2. Frontend on Vercel
1. vercel.com -> Add New -> Project -> import the repo.
2. Root Directory: `frontend`. Framework: Next.js (auto).
3. Environment variable `NEXT_PUBLIC_API_URL` = your Render URL (no trailing slash).
4. Deploy. Copy the Vercel URL into Render's `CORS_ORIGINS`, then save (Render redeploys).

## 3. Make accounts survive restarts (recommended)
Render's free disk is wiped on restart. Create a free Postgres at neon.tech, copy its
connection string, and set it as `DATABASE_URL` on Render. Tables and seed data are created on boot.

## Notes
- Free Render services sleep after ~15 min idle; the first request takes ~30-60 s.
- Camera proctoring needs HTTPS (Vercel provides it).
- No `LLM_API_KEY` -> the offline grader and template generator still work.
